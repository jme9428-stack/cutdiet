1시작하기 전에

데스크톱 크롬이나 엣지에서 열면 모든 기능이 됩니다. 휴대폰과 사파리에서는 분석·편집까지만 되고 MP4 만들기는 안 될 수 있습니다.

항목내용
잘 맞는 영상혼자 말하는 강의, 화면 녹화 설명, 브이로그 내레이션, 인터뷰
안 맞는 영상촬영 때부터 배경음악이 깔린 영상, 여러 명이 동시에 말하는 영상, 현장음이 큰 영상 (배경음악은 여기서 나중에 깔 수 있습니다)
길이10분 안팎이 가장 쾌적, 30분까지 무리 없음. 1시간이 넘으면 분석과 편집 프로그램용 파일만 만들어집니다
파일 형식MP4, MOV, WebM, MKV. 음성만 있는 파일(MP3·WAV·M4A)도 가능
컴퓨터 사양메모리 8GB 이상 권장. 자동 자막은 처음 한 번 음성 인식 모델(약 760MB)을 내려받습니다
영상은 어디로어디에도 올라가지 않습니다. 결과 파일은 내가 고른 위치(또는 다운로드 폴더)에만 저장됩니다

23단계로 끝내기

  1. 영상 넣기가운데 점선 상자에 파일을 끌어다 놓거나 클릭해 고릅니다. 10분 영상이면 20~40초 뒤 분석이 끝나고, 아래 타임라인 파형이 초록 = 남김 빨강 = 삭제로 칠해집니다. 오른쪽에 "편집 후 길이"와 "줄어드는 시간"이 뜹니다.
  2. 들어보며 고치기재생(또는 Space)을 누르면 빨간 구간을 건너뛰며 완성본처럼 들립니다. 말이 잘렸거나 쉼이 너무 길면 그 자리에서 멈추고 고칩니다(4장). 전체가 어색하면 왼쪽 컷 메뉴에서 프리셋(강의형 / 토크·인터뷰 / 브이로그)을 바꿔 봅니다.
  3. 내보내기오른쪽 위 내보내기 → MP4 만들기. 저장 위치를 고르는 창이 먼저 뜨고, 저장을 누르면 렌더링이 시작되어 그 파일로 바로 저장됩니다(크롬·엣지). 작업은 같은 브라우저에 자동 저장되어, 같은 영상을 다시 열면 이어서 할 수 있습니다.
렌더링 시간 보통 영상 길이의 10~30%입니다(10분 영상 → 1~3분). 그동안 다른 메뉴를 써도 되지만, 브라우저 탭을 닫으면 멈춥니다.

5자동 자막

  1. 자막 만들기왼쪽 자막 → 자동 자막 만들기. 처음 한 번 음성 인식 모델(약 760MB)을 내려받고, 그다음부터는 바로 시작합니다. 영상 길이와 비슷한 시간이 걸립니다(10분 영상 ≈ 10분). 그동안 다른 메뉴에서 계속 작업해도 됩니다.
  2. 틀린 글자 고치기목록에서 줄을 누르면 그 위치로 가고, 글자를 바로 고칠 수 있습니다. 미리보기의 자막을 더블클릭하거나, 오른쪽 속성 창에서 고쳐도 됩니다. 같은 오타가 여러 번 나오면 "찾아 바꾸기".
  3. 스타일 고르기같은 메뉴 아래 자막 스타일에서 "자막을 영상에 굽기"를 켜고 스타일을 고릅니다. 미리보기에 그대로 보이고 MP4에 새겨집니다.
알아 두면 좋은 것내용
정확도기본 모델(가장 정확 · large-v3-turbo)로 실제 강의 영상에서 틀린 단어가 약 4~5%였습니다(이전 모델 11%). 급할 때는 "인식 설정"에서 빠름(small)을 고르면 2배 빠르지만 덜 정확합니다
한 줄 자막자막은 늘 한 줄입니다. 한 줄 16자(한글 1자, 영문·숫자·띄어쓰기 0.5자)가 기본이고, 숏츠는 12자, 길게는 20자. 화면보다 길면 글자가 자동으로 작아집니다
자연스러운 끊기문장 끝(-습니다, -어요)에서 끊고, "그리고·그래서"는 다음 줄 앞으로, "작은 / 것을"처럼 말이 이어지는 곳은 끊지 않습니다. 고친 뒤에는 "문장 단위로 다시 나누기"
읽기 속도초당 12자 이하로 읽히도록 표시 시간을 맞추고, 줄 끝 마침표·쉼표는 뺍니다 (넷플릭스 한국어 자막 기준)
SRT 파일내보내기 → SRT(편집 후 시간)를 캡컷이나 유튜브에 그대로 올릴 수 있습니다. 반대로 SRT 불러오기도 됩니다

6NG 정리 (추임새·말 버벅임)

영상을 넣으면 자막 없이도 소리만으로 길게 끈 "어…·음…", 같은 소리로 다시 시작한 말 버벅임, 다시 말한 NG를 후보로 찾습니다. 자동 자막을 만들면 말 내용까지 보고 더 정확하게 다시 찾습니다.

  1. 듣고 고르기왼쪽 NG 정리에서 후보마다 ▶로 들어보고, 지울 것만 체크합니다. 확실한 것은 미리 체크되어 있습니다. 시작·끝 시간도 고칠 수 있습니다.
  2. 삭제 표시"체크한 항목 지우기"를 누르면 그 구간이 빨간색(삭제)이 됩니다. 지운 말은 자막 글자에서도 빠집니다. 마음이 바뀌면 Ctrl+Z.

종류별로 켜고 끌 수 있습니다: 추임새, 말 버벅임("그 그러니까"·말 꼬임), 다시 말한 NG, 웅얼거림(인식 안 된 소리). 타임라인에는 후보 자리가 따로 표시됩니다.

7텍스트·오디오·효과·숏츠

메뉴쓰는 때핵심 사용법
텍스트강조 문구, 제목, 로고·워터마크문구 입력 → 텍스트 추가(재생 위치부터 3초). 미리보기에서 끌어 옮기고, 오른쪽 속성 창에서 글꼴·색·크기·시간. 여러 개가 겹치면 레이어로 위아래 쌓입니다. 이미지·로고는 범위 "영상 전체"로 두면 워터마크
오디오배경음악, 효과음음악 파일 선택 → 음량(15~25% 권장) → "말할 때 음악 줄이기" 켜기. 타임라인 음악 트랙을 끌어 시작 위치 조절. 효과음은 재생 위치에 추가
효과점프컷 숨기기, 화면 전환자동 줌(컷마다 살짝 확대해 튐을 가림), 구간 줌, 페이드 인/아웃, 디졸브, 밝기·대비·채도
숏츠같은 영상으로 세로 숏츠시작/끝 "현재 위치로" → 미리보기의 노란 9:16 틀을 끌어 위치 → 숏츠 MP4 만들기. 자막·텍스트·효과도 같이 들어갑니다

8내보내기와 캡컷으로 가져가기

결과물쓰는 곳
MP4유튜브 업로드, 캡컷 가져오기. 화질은 "고화질 · 원본 해상도" 권장
SRT 자막유튜브 자막 업로드, 캡컷 자막 가져오기 (편집 후 시간으로 딱 맞음)
유튜브 챕터설명란에 붙여 넣는 타임스탬프 (첫 챕터 0:00, 3개 이상, 10초 간격을 자동 검사)
썸네일 후보목소리에 힘이 있는 순간의 프레임 → JPG
EDL · XML · FFmpeg프리미어·다빈치·파이널컷 사용자용 컷 패키지 (캡컷은 필요 없음)
프로젝트 파일다른 컴퓨터에서 이어서 작업할 때만. 같은 컴퓨터는 같은 영상을 다시 열면 이어서 할지 묻습니다

캡컷으로 가져가기

  • 여기서 컷만 하고 MP4를 만들어 캡컷에 가져가면, 자막·스티커·효과만 올리면 됩니다.
  • 자막은 여기서 만든 SRT(편집 후 시간)를 캡컷에 가져와도 시간이 딱 맞습니다.

캡컷 없이 끝내기

  • 자동 자막 → 자막 스타일에서 "영상에 굽기" → 필요하면 텍스트·음악·자동 줌 → MP4 만들기. 그대로 업로드하면 됩니다.

9무료 버전과 Pro의 차이

편집 기능(컷·자막·NG 정리·텍스트·오디오·효과·숏츠·내보내기)은 두 버전이 똑같습니다. Pro는 영상을 많이, 자주, 빠르게 처리하는 사람을 위한 자동화와 속도 도구가 더해진 버전입니다.

항목무료 (cutdiet.vercel.app)Pro (/pro.html)
편집 기능 전체✔ 같음✔ 같음
여러 영상 한 번에한 번에 한 영상큐 자동 처리: 여러 파일을 넣으면 분석 → MP4 → 숏츠 → 썸네일 → 프로젝트 저장까지 차례로
채널 기본값매번 프리셋·화질 선택프리셋·화질·크롭 위치·음악 음량을 고정해 새 영상에 자동 적용
저장파일마다 저장 위치 선택출력 폴더를 한 번 정하면 저장 창 없이 쌓임
단축키기본 단축키숫자키 1~9로 메뉴 전환, 모든 단축키를 원하는 키로 변경, 단축키 표(/)

증상조치
"이 파일을 분석하지 못했습니다"카메라 원본 코덱을 브라우저가 못 읽는 경우. 휴대폰·카메라 설정에서 "호환성 우선(H.264)"으로 촬영하거나, 한 번 MP4(H.264)로 변환해 넣으세요
분석은 되는데 화면이 검은색브라우저가 재생만 못 하는 형식. 컷·내보내기는 그대로 되고, 들어보려면 MP4(H.264)로 변환
MP4 만들기 버튼이 회색버튼 아래 회색 글씨에 이유가 적혀 있습니다. 대개 "크롬·엣지 데스크톱에서 열기" 또는 "1시간 초과"
저장 창을 닫았더니 렌더링이 시작되지 않는다정상입니다. 저장 위치를 고르지 않으면 시작하지 않습니다. MP4 만들기를 다시 누르세요
렌더링이 중간에 실패화질을 1080p나 720p로 낮춰 다시. 다른 탭·프로그램을 닫으면 메모리가 늘어납니다
자동 자막이 너무 오래 걸린다"인식 설정"에서 빠름(small)으로 바꾸면 약 2배 빠릅니다(정확도는 낮아짐). 처음 한 번은 모델 다운로드 시간이 더해집니다. 메모리가 부족하면 다른 탭을 닫으세요
자막에 틀린 단어가 있다목록이나 속성 창에서 고치고, 같은 오타는 "찾아 바꾸기". 무음 구간의 헛소리는 자동으로 걸러집니다
자막이 너무 짧게/길게 끊긴다"한 줄 글자 수"를 12·16·20자 중에서 바꾸고 "문장 단위로 다시 나누기"
자막 글자가 작아졌다한 줄이 화면보다 길어 자동으로 줄인 것입니다. 그 줄을 나누거나(속성 창 ✂) 글자 수를 줄이세요
배경음악이 다음에 열면 사라져 있다음악 파일은 브라우저에 저장되지 않습니다. 다시 선택하면 음량·덕킹 설정은 그대로 있습니다
이전 작업을 이어서 하고 싶다같은 컴퓨터: 같은 영상을 다시 열면 복구 여부를 묻습니다. 다른 컴퓨터: 위 막대 저장(.json) 후 불러오기
영상이 어디에 저장되나저장되지 않습니다. 브라우저 탭을 닫으면 영상은 메모리에서 사라지고, 컷·자막 정보만 남습니다

편집 시간을 줄이는 촬영·편집 습관 7가지

  1. 원고나 개요를 보고 촬영하세요. NG가 줄면 컷편집이 가장 크게 줍니다.
  2. NG가 나면 2~3초 입을 다물고 다시 시작하세요. 긴 정적은 자동 컷이 가장 정확하게 잡는 신호입니다.
  3. 박수 한 번으로 표시를 남기세요. 파형에 뾰족하게 남아 타임라인에서 바로 찾습니다.
  4. 1차 컷은 기계에게, 판단은 사람에게. 자동 결과를 받아들이고 들으며 어색한 곳만 고치세요.
  5. 자막·효과는 컷이 확정된 뒤에 넣으세요.
  6. 반복되는 결정은 기본값으로. 프리셋·화질·음악 음량은 한 번 정하고 다시 고민하지 마세요.
  7. 챕터는 편집하면서 M키로 찍으세요.
