1시작하기 전에

데스크톱 크롬이나 엣지에서 열면 모든 기능이 됩니다. 휴대폰과 사파리에서는 분석까지만 되고 MP4 만들기는 안 될 수 있습니다.

항목내용
잘 맞는 영상혼자 말하는 강의, 화면 녹화 설명, 브이로그 내레이션, 인터뷰
안 맞는 영상촬영 때부터 배경음악이 깔린 영상, 여러 명이 동시에 말하는 영상, 현장음이 큰 영상 (배경음악은 여기서 나중에 깔 수 있습니다)

파일 형식MP4, MOV, WebM, MKV. 음성만 있는 파일(MP3·WAV·M4A)도 가능
영상은 어디로어디에도 올라가지 않습니다. 결과 파일은 내가 고른 위치(또는 다운로드 폴더)에만 저장됩니다
처음 열 때3단계 안내가 한 번 뜨고, 예시 데이터가 채워져 있습니다. 내 영상을 넣으면 바뀝니다

23단계로 끝내기

  1. 영상 올리기화면 위 점선 상자에 파일을 끌어다 놓거나 클릭해 고릅니다. 10분 영상이면 20~40초 뒤 분석이 끝나고, 타임라인에 유지 초록과 삭제 빨강 구간이 그려집니다. 오른쪽 패널에 "편집 후 길이"와 "줄어드는 시간"이 뜹니다.
  2. 들어보며 고치기재생 버튼(또는 Space)을 누르면 빨간 구간을 건너뛰며 완성본처럼 들립니다. 말이 잘렸거나 쉼이 너무 길면 그 자리에서 멈추고 고칩니다(3장). 전체가 어색하면 오른쪽 프리셋(강의형 / 토크·인터뷰 / 브이로그)을 바꿔 봅니다.
  3. 내보내기내보내기 탭에서 MP4 만들기를 누르면 저장 위치를 고르는 창이 먼저 뜹니다. 파일 이름을 정하고 저장을 누르면 렌더링이 시작되고 결과가 그 파일로 바로 저장됩니다(크롬·엣지). 작업은 같은 브라우저에 자동 저장되어, 같은 영상을 다시 열면 이어서 할 수 있습니다.
렌더링 시간 보통 영상 길이의 10~30%입니다(10분 영상 → 1~3분). 그동안 다른 탭을 열어도 되지만, 브라우저 탭을 닫으면 멈춥니다. 30분이 넘는 영상이나 4K는 시간이 오래 걸리고 메모리를 많이 쓰니 다른 프로그램을 닫아 두세요.

4캡컷으로 가져가기 / 캡컷 없이 끝내기

캡컷으로 자막과 효과를 꾸미는 분은 MP4만 가져가면 됩니다. 캡컷 없이 끝내고 싶으면 AI 자막과 꾸미기 탭을 추가로 쓰면 됩니다.

캡컷으로 가져가기

  1. 내보내기 탭 → MP4 만들기 (화질은 "고화질 · 원본 해상도"). 저장 위치를 고르면 렌더링이 시작됩니다.
  2. 캡컷에서 새 프로젝트 → 그 MP4를 가져오기. 컷은 이미 끝나 있으니 자막·스티커·효과만 올리면 됩니다.
  3. 자막은 캡컷 자동 자막으로 넣어도 되고, 여기서 만든 SRT(편집 후 시간)를 캡컷에 가져와도 됩니다. 시간이 딱 맞습니다.
  4. 유튜브 설명란에는 챕터 탭의 텍스트를 복사해 붙입니다.

캡컷은 EDL·XML 파일을 못 받으므로 "컷 패키지 zip"은 캡컷 사용자에겐 필요 없습니다. 프리미어·다빈치·파이널컷 사용자만 씁니다.

캡컷 없이 끝내기

  1. AI 자막·NG 탭 → 자막 만들기. 처음 한 번 모델 파일(60~190MB)을 내려받고, 10분 영상에 보통 3~15분 걸립니다. 그동안 다른 탭에서 계속 작업해도 됩니다.
  2. 자막 글자가 틀리면 미리보기 칸에서 직접 고칩니다. 추임새·반복 후보는 확인하고 체크한 항목 삭제 표시.
  3. 꾸미기 탭 → "자막을 영상에 굽기" 켜고 스타일 선택. 미리보기 화면에 그대로 보입니다.
  4. 원하면 자동 줌(점프컷 숨김), 효과음, 로고 이미지, 배경음악까지 얹고 내보내기 탭 → MP4 만들기. 그대로 업로드하면 됩니다.

6자주 묻는 질문과 문제 해결

증상조치
"이 파일을 분석하지 못했습니다"카메라 원본 코덱을 브라우저가 못 읽는 경우. 휴대폰·카메라 설정에서 "호환성 우선(H.264)"으로 촬영하거나, 한 번 MP4(H.264)로 변환해 넣으세요
분석은 되는데 화면이 검은색브라우저가 재생만 못 하는 형식. 컷·내보내기는 그대로 되고, 들어보려면 MP4(H.264)로 변환
MP4 만들기 버튼이 회색버튼 위 회색 글씨에 이유가 적혀 있습니다. 대개 "크롬·엣지 데스크톱에서 열기" 또는 "1시간 초과"
저장 창을 닫았더니 렌더링이 시작되지 않는다정상입니다. 저장 위치를 고르지 않으면 렌더링을 시작하지 않습니다. MP4 만들기를 다시 누르세요
렌더링이 중간에 실패화질을 1080p나 720p로 낮춰 다시. 다른 탭·프로그램을 닫으면 메모리가 늘어납니다
저장 창이 안 뜨고 파일도 없다저장 창이 없는 브라우저(사파리·파이어폭스)에서는 다운로드로 저장됩니다. 주소창 오른쪽 다운로드 아이콘을 확인하고, 없으면 "다시 저장" 클릭
말이 중간에 잘린다 / 숨소리가 남는다3장의 설정 표 참고
AI 자막이 너무 오래 걸린다"빠름 · base" 모델로 바꾸거나 GPU 가속 체크(최신 크롬). 처음 한 번은 모델 다운로드 시간이 더해집니다
AI 자막에 없는 말이 들어간다음성 인식의 한계입니다. 미리보기 칸에서 직접 고치세요. 무음 구간의 헛소리는 자동으로 걸러집니다
배경음악이 다음에 열면 사라져 있다음악 파일은 브라우저에 저장되지 않습니다. 다시 선택하면 음량·덕킹 설정은 그대로 있습니다
이전 작업을 이어서 하고 싶다같은 컴퓨터: 같은 영상을 다시 열면 복구 여부를 묻습니다. 다른 컴퓨터: 프로젝트 저장(.json) 후 불러오기
영상이 어디에 저장되나저장되지 않습니다. 브라우저 탭을 닫으면 영상은 메모리에서 사라지고, 컷 정보만 남습니다
정확한 프레임 단위인가MP4 렌더는 프레임 단위로 정확합니다. EDL은 프레임레이트 설정이 영상과 같아야 합니다

편집 시간을 줄이는 촬영·편집 습관 7가지

  • 원고나 개요를 보고 촬영하세요. NG가 줄면 컷편집이 가장 크게 줍니다. 편집은 더하는 일이 아니라 빼는 일입니다.
  • NG가 나면 2~3초 입을 다물고 다시 시작하세요. 긴 정적은 자동 컷이 가장 정확하게 잡는 신호입니다.
  • 박수 한 번으로 표시를 남기세요. 파형에 뾰족하게 남아 타임라인에서 바로 찾을 수 있습니다.
  • 1차 컷은 기계에게, 판단은 사람에게. 자동 결과를 받아들이고 "삭제 구간 건너뛰기"로 들으며 어색한 곳만 고치세요.
  • 자막·효과는 컷이 확정된 뒤에 넣으세요. 컷이 바뀌면 자막 타이밍을 다시 맞춰야 합니다.
  • 반복되는 결정은 기본값으로. 프리셋·화질·음악 음량은 한 번 정하고 다시 고민하지 마세요.
  • 챕터는 편집하면서 M키로 찍으세요. 업로드할 때 영상을 처음부터 다시 보는 일을 없앱니다.
