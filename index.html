        ③ 숏츠 MP4 만들기 확인 중

        삭제 구간은 숏츠에서도 빠지고, 배경음악을 설정했다면 같이 들어갑니다. 자막·스티커는 캡컷에서 올리세요. 유튜브 쇼츠는 세로 영상 기준 최대 3분입니다.

        목소리가 가장 힘 있게 나오는 순간(표정이 살아 있는 구간)을 골라 12장을 보여줍니다. 썸네일 작업의 출발점으로 쓰세요.

        ① 자막 만들기 내 PC에서 처리 · 무료

        음성 인식 모델이 내 브라우저 안에서 돌아갑니다. 서버도 API 비용도 없고, 음성이 밖으로 나가지 않습니다. 처음 한 번 모델 파일을 내려받고(이후 저장됨), 10분 영상 기준 보통 3~15분 걸립니다(기기 성능에 따라 다름). 그동안 다른 탭에서 계속 작업할 수 있습니다.

        영상을 불러온 뒤 실행하세요.

        ② 자막 내보내기

        편집 후 시간 SRT는 ①에서 만든 MP4에 그대로 맞습니다. 캡컷·유튜브 스튜디오에 올리세요. 원본 시간 SRT는 EDL로 편집 프로그램에서 작업할 때 씁니다. 인식 결과는 틀릴 수 있으니 한 번 훑어보세요.

        ③ 삭제 후보 · 추임새와 반복(NG) 0개

        "어·음" 같은 추임새와, 같은 말을 다시 한 구간(앞의 것이 NG)을 찾아 보여줍니다. 확실한 것은 미리 체크돼 있고, 애매한 것은 비워 둡니다. 체크한 항목 삭제 표시를 누르면 타임라인에 반영되고 Ctrl+Z로 되돌릴 수 있습니다.

        종류시간내용길이
        자막을 만들면 후보가 여기에 표시됩니다.

        ① MP4로 바로 렌더링 확인 중

        캡컷 사용자는 이 길입니다. 캡컷은 EDL·XML을 불러오지 못하므로, 여기서 만든 MP4를 캡컷에 넣고 자막·효과를 올리세요. 서버 업로드 없이 이 브라우저에서 만들며, 보통 영상 길이의 10~30% 시간이 걸립니다. 버튼을 누르면 저장 위치를 먼저 고르고(크롬·엣지), 렌더링 결과가 그 파일로 바로 저장됩니다. 저장 창이 없는 브라우저에서는 끝난 뒤 다운로드 폴더에 저장됩니다.

        30분이 넘는 영상이나 4K는 시간이 오래 걸리고 메모리를 많이 씁니다. 1시간이 넘으면 렌더링 대신 ②의 FFmpeg 스크립트를 쓰세요.

        ② 편집 프로그램으로 가져가기

        프리미어·다빈치는 EDL, 파이널컷은 FCPXML로 컷 타임라인을 그대로 불러옵니다. 정확한 컷본 파일이 필요하면 FFmpeg 스크립트가 가장 안정적입니다.

        자동 감지값. 영상 설정과 다르면 고치세요.

        zip 안에는 EDL, FCPXML, FFmpeg 스크립트(.sh/.bat), 챕터 텍스트, 프로젝트 파일, 사용법(README)이 들어 있습니다. 배경음악을 설정했다면 음악 파일과 믹싱 필터도 함께 들어갑니다.

        프로그램별 불러오는 법
        • 캡컷: ①의 MP4를 미디어로 가져오면 끝. 챕터는 ③을 설명란에 붙여넣기.
        • 프리미어 프로: 파일 → 가져오기 → .edl → 새 시퀀스가 생깁니다. 오프라인 클립 우클릭 → 미디어 연결 → 원본 영상 지정.
        • 다빈치 리졸브: 원본 영상을 미디어 풀에 먼저 넣고, 파일 → Import → Timeline → .edl (또는 .fcpxml).
        • 파이널컷: 파일 → 가져오기 → XML → .fcpxml. 미디어 재연결 창에서 원본 영상 지정.
        • FFmpeg: 원본 영상(과 음악 파일)과 같은 폴더에서 Mac: sh ffmpeg_cut.sh, Windows: ffmpeg_cut.bat 더블클릭.

        ③ 유튜브 챕터

        편집 후 시간 기준으로 환산된 타임스탬프입니다. 챕터 탭에서 제목을 고칠 수 있습니다.

        ④ 프로젝트 파일

        컷·챕터·설정을 JSON으로 저장해 두면 나중에 같은 영상을 다시 열어 이어서 작업할 수 있습니다. 작업 중에는 이 브라우저에 자동 저장됩니다.

        이 도구가 하는 일 / 하지 않는 일

        • 하는 일: 말이 없는 구간(쉼, NG 뒤의 정적, 생각하는 시간)을 소리 크기로 찾아 1차 컷을 자동으로 만듭니다. 사람은 결과를 듣고 고치기만 하면 됩니다.
        • 꾸미기 탭: 자막을 영상에 굽기(글꼴·색·외곽선·박스), 자동 줌으로 점프컷 숨기기, 구간 줌, 페이드, 디졸브 전환, 효과음 5종(+내 파일), 이미지·텍스트 오버레이. 미리보기에 그대로 보이고 MP4·숏츠에 반영됩니다.
        • AI 자막·NG 탭: 음성 인식을 내 PC에서 돌려 자막(SRT)을 만들고, "어·음" 추임새와 같은 말을 다시 한 NG 구간을 삭제 후보로 보여줍니다. 무료이고 음성이 밖으로 나가지 않지만, 시간이 걸리고 인식이 틀릴 수 있어 확인 후 적용합니다.
        • 잘 맞는 영상: 토킹헤드 강의, 브이로그 내레이션, 인터뷰, 화면 녹화 설명 영상.
        • 안 맞는 영상: 촬영 때부터 배경음악이 깔린 영상, 여러 사람이 동시에 말하는 영상, 현장음이 큰 영상. (배경음악은 여기서 나중에 까는 것을 권합니다.)
        • 길이: 10분 안팎이 가장 쾌적하고 30분까지 무리 없습니다. 1시간이 넘는 영상은 분석·컷 목록·EDL/FFmpeg 내보내기만 지원합니다.

        편집 시간을 줄이는 촬영·편집 습관 7가지

        1. 원고나 개요를 보고 촬영하세요. NG가 줄면 컷편집이 가장 크게 줍니다. 편집은 더하는 일이 아니라 빼는 일입니다.
        2. NG가 나면 2~3초 입을 다물고 다시 시작하세요. 긴 정적은 자동 컷이 가장 정확하게 잡는 신호입니다.
        3. 박수 한 번으로 표시를 남기세요. 파형에 뾰족하게 남아 타임라인에서 바로 찾을 수 있습니다.
        4. 1차 컷은 기계에게, 판단은 사람에게. 자동 결과를 받아들이고 "삭제 구간 건너뛰기"로 들으며 어색한 곳만 고치세요.
        5. 자막·효과는 컷이 확정된 뒤에 넣으세요. 컷이 바뀌면 자막 타이밍을 다시 맞춰야 합니다.
        6. 반복되는 결정은 기본값으로. 프리셋·화질·음악 음량은 한 번 정하고 다시 고민하지 마세요.
        7. 챕터는 편집하면서 M키로 찍으세요. 업로드할 때 영상을 처음부터 다시 보는 일을 없앱니다.

        자주 묻는 질문

        • 영상이 어디로 올라가나요? 어디에도 올라가지 않습니다. 분석과 렌더링 모두 이 브라우저 안에서 처리되고, 파일은 내가 고른 위치(또는 다운로드 폴더)에만 남습니다.
        • 어떤 브라우저가 좋나요? 최신 크롬·엣지(데스크톱)에서 MP4 렌더링까지 모두 됩니다. 사파리·파이어폭스는 분석과 EDL 내보내기는 되지만 MP4 렌더링은 안 될 수 있습니다.
        • 말이 중간에 잘려요. 세부 설정에서 말소리 기준을 낮추고(-48 정도) 여백을 0.25초로 늘리세요. 녹음 자체가 작으면 기준을 더 낮춰야 합니다.
        • 숨소리까지 다 남아요. 말소리 기준을 올리고(-36 정도) 최소 무음 길이를 줄이세요.
        • 프레임이 정확한가요? 브라우저 렌더링과 FFmpeg 스크립트는 프레임 단위로 정확합니다. EDL·FCPXML은 프레임레이트 설정이 영상과 같아야 합니다.
        • 이전 작업을 이어서 할 수 있나요? 같은 영상을 다시 열면 이 브라우저에 자동 저장된 작업을 복구할지 물어봅니다. 다른 기기에서 이어가려면 프로젝트(.json)를 저장해 두세요.

        컷편집, 3단계면 끝납니다

        1. 영상 올리기촬영한 원본을 그대로 넣으세요. 업로드가 아니라 내 브라우저 안에서만 분석됩니다. 10분 영상이면 20~40초 걸립니다.
        2. 들어보며 고치기무음·NG 뒤 정적이 자동으로 빨갛게 잡힙니다. 재생 버튼을 누르면 빨간 구간을 건너뛰며 들리니, 어색한 곳에서만 Q·W·X로 고치세요.
        3. 내보내기MP4 만들기를 누르고 저장 위치를 고르면 렌더링이 시작됩니다. 캡컷을 쓰면 그 MP4를 캡컷에 넣고 자막만 올리면 됩니다. 캡컷 없이 끝내려면 AI 자막을 만들고 꾸미기 탭에서 자막·효과·효과음을 얹어 MP4로 내보내세요.
